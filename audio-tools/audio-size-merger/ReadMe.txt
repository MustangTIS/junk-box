==================================================
 音楽ファイル サイズ比較マージツール
==================================================

【概要】
2つのフォルダ（ルートA：メイン、ルートB：重複・取り込み側）の構造を比較し、
同じ相対パスにあるファイルのサイズをチェックして、ルートB側のファイルの方が
大きい場合のみルートA側を上書き（または新規追加）する統合ツールです。


【機能・特徴】
・2つの独立したフォルダパスをGUIでそれぞれ選択可能。
・ファイルサイズ（bytes）を比較し、より高品質・大容量なファイル（Bの方が大きい場合）
  のみを安全に上書きコピー。
・ルートAに存在しない新規ファイルは、そのままルートA側に自動追加。
・詳細な処理ログ（サイズ比較の結果や上書き・スキップの判定）がリアルタイムで表示されます。


【使い方】
1. Python 3.x 環境でスクリプトを実行します。(若しくはRun.batを実行)
2. ルートA（元・メインとなる保存先）フォルダを指定します。
3. ルートB（重複側・新しく取り込む側）フォルダを指定します。
4. 「比較して上書き統合を実行」ボタンをクリックします。


【注意事項】
・ルートA側の既存ファイルが上書きされる可能性があるため、実行前には
  あらかじめ大切なデータのバックアップを取得しておくことをおすすめします。
