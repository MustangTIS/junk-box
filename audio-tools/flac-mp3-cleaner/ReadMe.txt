==================================================
 同名FLAC優先 MP3クリーナー
==================================================

【概要】
指定したフォルダ内を再帰的に走査し、同じフォルダ内に同じファイル名で
「FLAC」と「MP3」の両方が存在する場合に、不要になったMP3側を自動で
削除または別フォルダへ退避するツールです。
（音源の高音質化に伴い、不要になった圧縮音源を掃除する用途に便利です）


【機能・特徴】
・TkinterによるシンプルなGUIで対象フォルダを選択可能。
・安全モード（_Removed_MP3_Backup フォルダへ階層を維持して移動）と、
  完全削除モードをラジオボタンで切り替え可能。
・リアルタイムの処理ログ表示により、どのファイルが処理されたか一目で確認できます。


【使い方】
1. Python 3.x 環境でスクリプトを実行します。
2. 「参照...」ボタンから整理対象のルートフォルダを選択します。
3. 「安全モード」または「完全削除モード」のいずれかを選択します。
4. 「FLACがある重複MP3の整理を実行」ボタンをクリックします。


【注意事項】
・完全削除モードを選択した場合、ファイルはゴミ箱を経由せず完全に削除されます。
  心配な場合は初期設定の「安全モード」で実行してください。
