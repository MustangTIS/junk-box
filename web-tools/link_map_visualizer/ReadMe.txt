1. 概要
----------------------------------------------------------------------
本ツールは、指定したWebサイト（URL）を再帰的にクロール（スキャン）し、
サイト内の内部リンク構造や接続関係をグラフィカルに可視化（マッピング）する
単体デスクトップツールです。

pyvisによる物理シミュレーション描画を用いて、各ページの結合状態やハブ構造、
孤立ページ、404エラーなどの問題点をインタラクティブなHTMLマップとして出力・診断できます。


2. 主な機能
----------------------------------------------------------------------
・指定URL以下の内部リンクを自動巡回（同一ドメイン内 / 最大ページ数上限設定対応）
・HTTPステータスコードのチェック（404エラーページの検知と警告アイコン表示）
・pyvisを使用した内部リンク構造のインタラクティブなHTMLマップ（site_link_map.html）自動生成
・ブラウザの表示領域（100vh/100%）に自動追従する全画面レスポンシブ表示
・マルチスレッド処理によるGUIフリーズ防止


3. 使い方
----------------------------------------------------------------------
1. Python 3.x 環境でスクリプトを実行します。(もしくはRun.bat)
2. 「対象WebサイトのURL」に、解析したいサイトのURLを入力します。
   （例: https://example.com/）
3. 「最大巡回ページ数」を指定します（デフォルト: 200）。
4. 「解析スタート」ボタンを押すと、バックグラウンドでサイトのクロールが開始されます。
5. 解析が完了すると、自動的に「site_link_map.html」が生成され、
   既定のWebブラウザで可視化マップが開きます。


4. 依存ライブラリ
----------------------------------------------------------------------
本ツールを実行するには、以下の外部ライブラリが必要です。

  pip install requests beautifulsoup4 pyvis
