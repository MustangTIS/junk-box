1. 概要
----------------------------------------------------------------------
本ツールは、指定したWebサイト（URL）を再帰的にクロール（スキャン）し、
検出したHTMLページのリンク構造を解析して、ディレクトリ階層を反映した
「sitemap.xml」をGUI上で簡単に作成・出力できるデスクトップツールです。

フラットになりがちなXMLサイトマップの生成において、エクスプローラ風の
ツリー表示でページの存在位置を確認しながら、登録のON/OFFやプライオリティ
（priority）の調整を直感的に行えます。


2. 主な機能
----------------------------------------------------------------------
・指定URL以下のリンクを自動クロール（同一ドメイン内）
・ディレクトリ階層を意識したツリービュー表示
・ツリーの「登録」列のダブルクリックによる、サイトマップ含める／含めないの切り替え
・ツリーの「Priority」列のダブルクリックによる、数値（例: 1.0, 0.8 等）の簡単変更
・検索エンジン（Google等）の仕様に合わせた sitemap.xml の出力保存


3. 使い方
----------------------------------------------------------------------
1. Python 3.x 環境でスクリプトを実行します。(もしくはRun.bat)
2. 「取得先URL」に、対象となるご自身のWebサイトのURLを入力します。
   （例: https://example.com/）
3. 「スキャン開始」ボタンを押すと、サイト内のページ探索がバックグラウンドで始まります。
4. スキャンが完了すると、ツリービューにディレクトリ・ページ構造が展開されます。
   - 不要なページがある場合は、該当行の「登録」列をダブルクリックしてチェックを外します。
   - プライオリティを変更したい場合は、「Priority」列をダブルクリックして数値を書き換えます。
5. 画面右下の「sitemap.xml を保存」ボタンを押し、任意の場所に保存します。
