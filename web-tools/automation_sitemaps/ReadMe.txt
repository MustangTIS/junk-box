1. 概要
----------------------------------------------------------------------
本ツールは、指定したWebサイト（URL）をクロール（スキャン）し、
検出したHTMLページのリンク構造を解析して、ディレクトリ階層を反映した
「sitemap.xml」および必要に応じて「robots.txt」をGUI上で作成・出力
できるデスクトップツールです。

フラットになりがちなXMLサイトマップの生成において、階層ツリー表示で
ページの存在位置を確認しながら、登録のON/OFFやプライオリティ
（priority）、robots.txt の除外指定を直感的に調整できます。


2. 主な機能
----------------------------------------------------------------------
・指定URL以下のリンクを自動クロール（同一オリジン・上限件数指定／0で無制限）
・深いサブ階層にも対応したディレクトリ・ページツリー表示
・ルートURLの末尾スラッシュ正規化やXMLエスケープなど、Sitemapsプロトコルに
  沿ったクリーンな出力
・サブディレクトリの index.html / index.htm への初期 Priority (0.7) 自動設定
  （ルートは 1.0、その他一般ページは 0.6）
・ツリーの「登録」列ダブルクリックによる、サイトマップ含める／含めないの切替
・ツリーの「Priority」列ダブルクリックによる、数値（0.0〜1.0）の個別変更
・ツリーの「robots除外」列ダブルクリックによる、Disallow 対象指定
・保存したXMLファイル名／URLに追従する「Sitemap:」行を含めた robots.txt 出力
  （「robots.txt も出力する」チェックON時）
・「登録と連動する」オプション（初期ON）による、robots除外指定時の登録自動解除


3. 使い方
----------------------------------------------------------------------
1. Python 3.x（tkinter利用可能）環境でスクリプトを実行します。
   （※Windows環境では Run.bat 等からの起動にも対応）
2. 「取得先URL」に、対象となるWebサイトのURLを入力します。
   （例: https://example.com/）
3. 必要に応じて「上限(0=無制限)」を指定し、「スキャン開始」ボタンを押します。
4. スキャンが完了すると、ツリービューにディレクトリ・ページ構造が展開されます。
   ・サイトマップから外したいページは、「登録」列をダブルクリックして
     チェックを外します。
   ・プライオリティを変更したい場合は、「Priority」列をダブルクリックして
     0.0〜1.0 の数値を入力します。
   ・robots.txt で除外したいページやフォルダは、「robots除外」列を
     ダブルクリックしてチェックを入れます。
5. 「登録と連動する」のON/OFFや、「robots.txt も出力する」のチェックを
   必要に応じて設定します。
6. 画面右下の「サイトマップを保存」ボタンを押し、XMLファイルを保存します。
   「robots.txt も出力する」をONにしている場合は、続けて robots.txt の
   保存先を指定できます（Sitemap: 行は保存したXML名に自動追従します）。
