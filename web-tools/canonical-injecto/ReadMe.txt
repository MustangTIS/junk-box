==================================================
 HTML Canonicalタグ 自動挿入・更新ツール
==================================================

【概要】
ローカルにある複数のHTMLファイルに、正規ページのURLを指定する 
「Canonicalタグ」を再帰的に一括挿入・更新するためのPython GUIツールです。
ミラーサイト対策などに活用できます。


【機能・特徴】
・TkinterによるGUIを採用し、フォルダ選択ダイアログで対象フォルダを直感的に指定可能。
・ベースURLを入力してボタンを押すだけで、配下のすべてのHTMLファイルを自動スキャン。
・既存のCanonicalタグがあれば置換し、なければ </head> の直前に自動追加。
・別スレッド（マルチスレッド）処理により、大量のファイル処理時も画面がフリーズしません。


【使い方】
1. Python 3.x 環境でスクリプトを実行します。
   (例: python canonicaltag.py)

2. 起動したウィンドウの「ターゲットフォルダ」の「参照...」ボタンから、
   HTMLファイルが入っているフォルダを選択します。

3. 「ベースURL」に本家サイトのベースURL（例: https://example.com）を入力します。

4. 「実行する」ボタンをクリックすると、処理ログが流れて自動で書き換えが行われます。


【注意事項】
・ファイルを直接書き換えるため、実行前に必要に応じてバックアップを取ることをおすすめします。
