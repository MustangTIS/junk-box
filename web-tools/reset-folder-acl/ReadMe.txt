==================================================
 フォルダアクセス権 一括リセットツール
==================================================

【概要】
指定したフォルダの所有権を強制取得し、アクセス権をリセットして
AdministratorsとSYSTEMのフルコントロール権限を付与するツールです。


【使い方】
1. `Run.bat` をダブルクリックして実行します。
2. 画面の指示に従って対象のフォルダを選択します。
3. 確認画面で「はい」を選ぶと処理が始まります。


【注意事項】
・実行には管理者権限が必要です（UACが表示されたら「はい」を押してください）。
・処理を行うと既存のアクセス権がリセットされるため、必要に応じて
  共有設定やアクセス許可を再度設定し直してください。
